CIS Benchmarks Catalogue

A single, filterable Excel workbook listing every currently published CIS Benchmark, grouped by technology family with versions, support status, and links to each benchmark's page.

The CIS website lists benchmarks in expandable dropdowns that are hard to scan or filter all at once. This flattens the whole list into one spreadsheet so you can sort, filter, and find the one you need.

What's inside

CIS_Benchmarks_Catalogue.xlsx has three tabs:

Tab	Contents
Read Me	Overview, how to pick a benchmark, and notes on profiles and formats
Benchmarks	326 benchmarks across 82 technology families
DISA STIG	130 CIS Benchmarks built to align with DISA STIGs

Each row has: Category, Technology Family, Benchmark Name, Version, Support Status, and a link to the family's page.

How to use it
Filter Category to the layer you're hardening — operating system, cloud provider, database, network device, etc.
Filter Support Status to Current to hide benchmarks for products past end-of-support.
Match the Benchmark Name to your exact product version.
Open the Family Page link, then download the PDF from the CIS download form.
Good to know
Profiles: most benchmarks ship a Level 1 (safe baseline) and Level 2 (stricter, likelier to break things) profile. Start at Level 1.
Formats: the PDFs are free for non-commercial use. Machine-readable formats (XCCDF, Excel, build kits, CIS-CAT Pro scanning) require a CIS SecureSuite membership.
Support Status is not an official CIS field. It's a best-effort assessment of whether the underlying product is still under vendor support, added to help you skip benchmarks you likely don't need. Verify against your vendor's lifecycle page before relying on it.
